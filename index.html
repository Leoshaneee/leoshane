Student Visual Hierarchy Documentation

Document the specific CSS strategies you implemented for at least 5 elements to establish visual hierarchy.

Target Element / Class Hierarchy Principles Applied Implementation Details & Design Rationale
.hero-title (h1) Size & Scale, Color & Contrast, Reading Patterns Made this the largest text on the page (2.75rem, bold) with high-contrast text color so it acts as the primary Level 1 focal point in a Z-pattern layout flow.
.hero-title Size & Scale, Typography Hierarchy, Color & Contrast The hero title uses the largest font size, bold weight, and high-contrast white text against the dark blue background. This immediately establishes it as the primary focal point of the page.
.badge Color & Contrast, Proximity & Grouping, Typography Hierarchy The admissions badge uses a small uppercase font, gold text, and a subtle transparent background. Its placement directly above the hero title groups it with the main message while keeping it visually secondary.
.category Typography Hierarchy, Color & Contrast, Proximity & Grouping Each course category uses uppercase text, a smaller font size, and a light blue background. This helps users quickly identify the course type without competing with the card title.
.card-meta Proximity & Grouping, Negative Space, Alignment & Grids The duration and difficulty level are placed together using Flexbox with consistent spacing. Their compact layout groups related course information while keeping enough space from the description and course link.
#site-footer / .footer-links Alignment & Grids, Negative Space, Reading Patterns The footer uses Flexbox to align the copyright information and navigation links. Its smaller muted text and generous top spacing reduce its visual importance and clearly mark the end of the page content.
